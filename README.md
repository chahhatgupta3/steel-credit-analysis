# Tata Steel vs JSW Steel: FY25 Credit Comparison

Comparative credit model built from consolidated FY25 filings, with data quality checks, an EBITDA stress test and a bond quote parser.

- Net leverage: Tata 3.18x, JSW 3.29x (company-reported 3.2x, 3.34x)
- 4.5x breach point: Tata -29.3% EBITDA, JSW -26.9%
- Tools: Python (pandas, pytest), SQLite, Excel

See docs/PROCESS.md for definitions, data issues found, and how to rerun.
